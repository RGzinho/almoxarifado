# Guia de implementação
## Pré-requisitos de ambiente local
Para rodar o projeto em seu dispositivo você prescisa tr instalado:
* PHP v8.2 ou superior
* Composer, gerenciador de pacotes do PHP
* Filament, framework para o Laravel
* Node.js & NPM
* MySQL

## Checklist para a instalação
Para instala o projeto você deve:
* Criar a estrutura base de Dados no Laravel;
* Instalar o Filament;
* Configurar as variáveis ambiente ('.env');
* Rodar as aplicações do banco de dados ('migrations');
